# Amazon UK Keyword Rank Monitor · 0.7.1

在本地Chrome中记录Amazon英国站关键词下的自然搜索位置与可见Sponsored Products广告序位。支持按ASIN选词、分组、历史曲线、季节专区、本地SIF报告展示、品名筛选和排名曲线悬停提示。

本项目采用 **PolyForm Noncommercial 1.0.0**，仅按许可证允许的非商业用途提供使用、修改及分发权限。商业用途不在本许可证授权范围内。这是源码公开项目，不属于允许商业使用的标准开源项目。

项目仓库：[yuan91039-ai/-](https://github.com/yuan91039-ai/-)。公开版本从空配置开始，不包含作者的商品信息或业务数据。

## 首次使用

1. 下载并解压仓库 ZIP。在 Chrome 打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，选取包含 `manifest.json` 的本目录。
2. 打开插件面板。在“监控设置”中输入自己的ASIN和关键词；公开版本默认没有任何商品、品名或关键词配置。
3. 采集使用普通专用 Chrome 窗口，不需要无痕权限。设置面板中的英国邮编；插件会尝试切换并核对 Amazon 页面上实际显示的配送邮编及未登录状态。未能确认时会暂停，不记录该页排名。普通窗口使用当前 Chrome 配置文件，建议保持未登录。
4. 在面板选择本地数据文件夹并授权读写。保存设置，先选择第一页并点击“开始记录”。人工核对结果后，再按需启用每小时监控。

每个关键词通过临时搜索标签读取，读取后关闭；整轮完成、失败结束或手动结束后关闭插件创建的专用窗口。每个词完成后保存结果，页面超时会延后重试。保持电脑唤醒、Chrome运行。需要人工验证或地区状态不明时，本轮会暂停并保留窗口供处理。

## 数据与隐私

- 无内置产品清单、真实ASIN、商品品名、私有关键词策略或报告数据。示例测试里的 `TESTASIN01` 等字符串仅用于测试，不代表真实商品。
- 在面板填写的监控配置保存于当前Chrome扩展配置中，不需要修改或提交源文件。
- 排名记录写入使用者授权的本地文件夹。默认保留最近30天排名、最近200轮运行记录。
- 使用者采集的搜索结果标题可能包含真实商品信息。CSV、JSON、JSONL、截图和备份不要加入公开仓库。
- 本项目不包含账号、Cookie或API密钥，不向第三方上传采集记录。网站访问权限限于Amazon英国站搜索页面所属域名。

## 可选的SIF快照

广告占比面板读取使用者自行放入扩展目录的 `sifTraffic.json`。该文件已列入 `.gitignore`，发布代码时不会提供。它只是历史报告快照，不会自动连接SIF或产生实时广告流量占比。

快照格式示例（均为虚构数据）：

```json
{
  "version": 1,
  "marketplace": "UK",
  "exportedAt": "2000-01-01",
  "reports": [{
    "asin": "TESTASIN01",
    "product": "示例商品",
    "available": true,
    "period": "用户选择的报告周期",
    "sourceFile": "example.xlsx",
    "terms": [{
      "keyword": "example keyword",
      "naturalRatio": 0.4,
      "adRatio": 0.6,
      "trafficShare": 1
    }]
  }]
}
```

比例使用0到1的小数，未知值使用 `null`，不能用0代替未知。自然／广告占比表示该词内的报告流量构成，不是广告后台点击或订单数据。插件实采SP序位是另一项独立观察。

## 结果口径

自然排名为已扫描页面中明确未标注Sponsored的商品卡片累计位置；SP序位仅统计已扫描页面内识别到的广告卡片。地区、会话、时间和页面结构会影响结果。“本次未见”不等于没有投放广告。公开版不会自动推断父体或其他子体。排名总览可按品名、ASIN、关键词筛选；鼠标悬停趋势点会显示采集时间与自然排名。
